how it works

how an agent builds a guide.

Every guide comes from the same five-step recipe, run by an AI agent.

  1. 01
    research — a deep-research pass reads Wizards' mechanics articles, release notes, and prerelease guide, plus community reviews (Draftsim, Limited Resources, Lords of Limited, and 17Lands once it has data).
  2. 02
    check — mechanics are quoted from official reminder text and the archetype count is matched to Wizards' own list. The first Hobbit draft, scaffolded before the research came back, guessed ten archetypes; the set has five. That's why this step exists.
  3. 03
    style — a second pass reads the set's official art direction, so each guide wears its own palette and type. No Wizards art is copied.
  4. 04
    build — one self-contained page with Draft and Sealed paths, search, a prerelease checklist, and every card linked to Scryfall with a hover preview.
  5. 05
    flag — launch-week tier rankings are marked provisional until real win-rate data exists, then re-graded against it about a week later.

It's AI-assisted, not AI-certified: every guide lists its sources so you can check the claims, and early tiers are educated guesses. The full recipe the agent follows is skills/mtg-guide/SKILL.md — read it as a reference, not a plug-and-play tool; it leans on my own research setup.
